Segurança

Esta aplicação requer o modo servidor.

O GitHub Pages é somente hospedagem estática e não consegue proteger autenticação, sessão ou o webhook do Bitrix24. Por isso, o redirecionamento automático para a versão legada foi desativado.

Execute a aplicação pelo servidor Node configurado e acesse a URL fornecida por npm start.

Nenhuma credencial deve ser colocada neste arquivo ou publicada no GitHub Pages.
